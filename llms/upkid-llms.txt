# Upkid

> Upkid is a childcare staffing marketplace that connects early childhood programs — daycares and preschools — with qualified, pre-vetted substitute and full-time teachers. Programs post shifts and roles; educators find flexible teaching opportunities through the Upkid web app and mobile apps. Upkid operates across metro areas in Georgia, Utah, and Arizona, and is a Techstars portfolio company.

Upkid does not publish a public API, developer portal, or API documentation. Its web application (app.upkid.com) is a client of a Firebase backend, and no OpenAPI, GraphQL, or other machine-readable API surface is published.
