# Upkid

Upkid is a childcare staffing marketplace that connects early childhood programs — daycares and preschools — with qualified, pre-vetted substitute and full-time teachers. Programs post shifts and roles while educators find flexible teaching opportunities through the Upkid web and mobile apps, with an ATS-style Hiring Hub for full-time childcare hiring. Upkid operates across metro areas in Georgia, Utah, and Arizona.

Upkid publishes no public API, developer portal, or API documentation — its web app (app.upkid.com) is a client of a Firebase backend. This repository captures the company profile plus probed security posture and discovery artifacts.
